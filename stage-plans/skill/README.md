# Skill Plans

This directory is the coordination point for skill-related work only.

Keep skill plans, migration notes, and runtime follow-up checklists here so they do not get mixed with role, memory, commander, or general implementation plans.

Current boundary:

- Skill specs and first-pass executors live in `src/skills`.
- The old Python skill migration checklist lives in `SKILL_MIGRATION_CHECKLIST.md`.
- Runtime registry, tool routing, approval workflow, and platform write actions are tracked separately from the completed migration checklist.
